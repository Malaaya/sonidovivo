# Sonido Vivo - Monorepo FullStack

Proyecto FullStack para Duoc UC, integrado con **React (Frontend)**, **Spring Boot (Backend)** y **MySQL**, orquestado mediante Docker.

## 📂 Estructura del Proyecto
- `back/`: Código fuente y Dockerfile del Backend.
- `front/`: Código fuente y Dockerfile del Frontend (con Nginx).
- `docker-compose.yml`: Configuración para desarrollo local.
- `docker-compose.prod.yml`: Configuración para producción con imágenes desde Docker Hub.
